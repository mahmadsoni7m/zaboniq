# ENGLISH GAME (ZABONIQ)

Version 1.0

English learning game with Tajik explanations.
Built with Kotlin and Jetpack Compose.

APK is built by GitHub Actions.

## Design & animations

- Unified dark-glass design system (`ui/Theme.kt`, `ui/Components.kt`)
- Animated gradient background, intro splash, animated bottom navigation
- Staggered card entrances, bounce-press buttons, animated progress bars and rings
- Games: shake on wrong answer, confetti on success, haptic feedback, count-up XP
- Words: tap to expand examples, animated learned-check with list reordering
- Profile: animated level ring and achievement badges
